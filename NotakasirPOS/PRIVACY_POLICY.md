# Kebijakan Privasi — Notakasir POS

Notakasir POS bekerja **100% offline**. Data toko (produk, transaksi, pelanggan) tersimpan di perangkat Anda (SQLite/Room) dan tidak dikirim ke server kami.

- Kamera: hanya untuk scan barcode produk, diproses di perangkat.
- Bluetooth: hanya untuk mencetak ke printer thermal milik Anda.
- File: hanya saat Anda menekan Backup/Restore, file `.db` ditulis ke lokasi yang Anda pilih.
- Kontak pelanggan & WA: hanya dibuka via aplikasi WhatsApp atas perintah Anda.

Hubungi penjual untuk penghapusan data: cukup hapus aplikasi atau gunakan Restore dari backup kosong.
